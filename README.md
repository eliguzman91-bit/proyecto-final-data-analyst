# RetailPro - Proyecto de Análisis de Datos

Este proyecto analiza las ventas de RetailPro para identificar qué regiones y categorías están influyendo en la baja de las ventas.

## Herramientas utilizadas
- SQL Server
- Power BI
- Excel
- Power Query
- DAX
- GitHub

  ## Archivos principales
- `m4_consultas_negocio.sql`: consultas de negocio.
- `m5_consultas_joins.sql`: consultas con JOIN.
- `m5_preparacion_base.sql`: preparación de la base de datos.


## Cómo ejecutar los archivos SQL
1. Abrir SQL Server.
2. Ejecutar `ventas_tech_db.sql` para crear la base de datos.
3. Seleccionar la base `Ventas_Tech_DB`.
4. Abrir y ejecutar los archivos SQL del repositorio.
